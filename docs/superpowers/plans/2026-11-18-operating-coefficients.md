# Коефіцієнти під технологічними параметрами

**Мета** — показати нормативні коефіцієнти під полями НУЕ та ГВ. [Погоджений дизайн](../specs/2026-11-18-operating-coefficients-design.md).

- [x] У десктопному браузері відкрити вузол із водою за 180 °C і розчином за 20 °C. Перевірити, що тест очікує коефіцієнти `1,6 / 0,69` та `1,6 / 0,21` під полями й падає на поточному інтерфейсі.
- [x] У `app.js` вивести результати наявних функцій нормативного добору під кожним набором полів. Використати поточний цикл оновлення форми й закрити попередній перегляд на кроці `operating`.
- [x] У `styles.css` віддати формі область після навігації, обмежити ширину полів і кнопок та видалити стилі карток, які більше не використовуються.
- [x] Повторити браузерну перевірку. Змінити середовище й температуру НУЕ, очистити поля та перейти до «Прокладки» й назад. Запустити `node scripts/check.cjs`.
