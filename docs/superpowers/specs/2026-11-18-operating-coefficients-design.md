# Коефіцієнти під технологічними параметрами

На кроці «Технологічні параметри» інженер має бачити введені дані один раз і одразу бачити коефіцієнти прокладки для кожного режиму.

## Варіанти

- Окрема таблиця праворуч містить два рядки для порівняння коефіцієнтів НУЕ та ГВ. Погляд переходить між формою й таблицею.
- Обрано коефіцієнти під полями. Кожен режим читається згори вниз, від введених даних до значень із нормативних таблиць. Форма стає вищою на два рядки.

## Поведінка

- Крок зберігає дві колонки, НУЕ та ГВ. У кожній після поля «Середовище» йдуть два рядки для перегляду. Перший показує коефіцієнт середовища *m* за таблицею Б.1. Другий показує коефіцієнт розширення *α* за таблицею Б.2 в 10⁻⁶/°C.
- Значення оновлюються під час редагування. *m* залежить від середовища, *α* від температури. Для відсутнього значення показується «—».
- На цьому кроці форма займає область праворуч від навігації, а ширина полів обмежена для читання на десктопі. Праву панель прибираємо з цього кроку.
- Зміна охоплює відображення технологічних параметрів. Коефіцієнти беруться з наявних функцій нормативного добору.

## Перевірка

У десктопному інтерфейсі перевірити два режими, оновлення після зміни середовища й температури, стан із порожніми полями та перехід до кроку «Прокладка». Запустити `node scripts/check.cjs`.
