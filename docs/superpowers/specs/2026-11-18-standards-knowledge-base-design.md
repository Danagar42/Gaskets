# База знань нормативних стандартів (StandardsBase)

Дата: 18.11.2026
Статус: Погоджено користувачем (Architectural)
Розташування застосунку: `d:\Розробка\Прокладки\standards-base/`
Дизайн-система: Modern Engineering Glass 2.0 (`D:\Розробка\SuperBase`)

---

## 1. Мета та огляд проєкту

Створення автономної бази знань нормативних стандартів на базі верифікованих інженерних даних репозиторію `Прокладки`. Застосунок призначений для інженерів-розрахунcountчиків і дозволяє:
- Швидко переглядати будь-який нормативний стандарт кріпильних виробів (гайки, шайби, різьби, моменти затягування).
- Досліджувати таблиці розмірів із миттєвою фільтрацією за діаметром різьби.
- Переглядати інтерактивне векторне 2D-креслення деталі (SVG) з виносними стрілками та точними числовими значеннями розмірів для обраного рядка таблиці.
- Використовувати дизайн-систему Modern Engineering Glass 2.0 (локальний Tailwind CSS, темна/світла теми, склоподібні панелі, інженерна типографіка) для подальшої безшовної інтеграції з проєктом `SuperBase`.

---

## 2. Архітектура та структура файлів

Застосунок розміщується у піддиректорії `standards-base/`:

```
standards-base/
├── index.html                 # Головний HTML-каркас: шапка, сайдбар, паспорт стандарту, таблиця, креслення
├── styles.css                 # Специфічні стилі Glass 2.0 + стилі креслень (CAD Light / Blueprint Dark)
├── assets/
│   ├── tailwind-local.css     # Повний локальний Tailwind CSS v3 (копія з SuperBase/assets/)
│   └── favicon.png            # Іконка застосунку
└── src/
    ├── app.js                 # Головний контролер стану, роутер категорій та обробник подій
    ├── catalog-adapter.js     # Адаптер FlangeStandardsDB: нормалізація даних, метадані, пошук
    ├── drawing-engine.js      # Векторний генератор SVG із розмірними виносними лініями
    └── drawing-templates.js   # Геометричні параметричні креслення (гайки, шайби, різьби, моменти)
```

### Джерело даних (Single Source of Truth)
- `index.html` підключає файл `../standards.bundle.js`.
- Джерелом правди є глобальний об'єкт `FlangeStandardsDB`, згенерований з `standards/**/*.json`.
- Жодного дублювання чи копіювання числових розмірів у `standards-base`. Оновлення JSON-стандартів у репозиторії автоматично оновлює базу знань.

## 3. Обсяг нормативних даних (Етап 1: Кріпильні елементи)

### 3.1. Гайки шестигранні (Nuts)
- **ГОСТ 5915-70:** Гайки шестигранні класу точності B ($m$, $S$, $d$, нерекомендовані діаметри).
- **ГОСТ 5927-70:** Гайки шестигранні класу точності A ($m$, $S$, $d$).
- **ГОСТ 9064-75:** Гайки для фланцевих з'єднань ($m$, $S$, $d$).
- **ГОСТ 10605-94:** Гайки шестигранні великих діаметрів M52–M150.
- **ГОСТ ISO 4032-2014:** Гайки шестигранні нормальні (ISO стандарт).

### 3.2. Шайби (Washers)
- **ГОСТ 11371-78:** Шайби плоскі нормального ряду (класи точності A і C, виконання 1 і 2, внутрішній діаметр $d_1$, зовнішній $d_2$, товщина $s$).
- **ГОСТ 6402-70:** Шайби пружинні (гровери), виконання 1 (нормальні).
- **ГОСТ 9065-75:** Шайби для фланцевих з'єднань.

### 3.3. Метричні різьби (Threads)
- **ГОСТ 24705-2004:** Номінальний діаметр $d$, великий (основний) крок різьби $P$, ряд дрібних кроків різьби $P_i$.

### 3.4. Моменти затягування (Torques)
- **Таблиця 1:** Допустимі моменти затягування кріпильних виробів (min/max Н·м та min/max кгс·м для різьб від M6 до M48).

### 3.5. Заділ на наступні етапи
- Вкладки верхнього рівня «Фланці» (ГОСТ 12820-80, 12821-80) та «Прокладки» (графітові ТРГ тощо) присутні у структурі інтерфейсу з бейджем *«В розробці»*.

## 4. Інтерфейс користувача та взаємодія (Master-Detail)

### 4.1. Шапка (Header)
- Логотип `SuperBase` з інженерним написом `База знань стандартів`.
- Навігаційні вкладки першого рівня: `Кріпильні елементи` (активна), `Фланці` (*незабаром*), `Прокладки` (*незабаром*).
- Посилання повернення: `← Робочий простір "Прокладки"`.
- Перемикач теми (Світла / Темна) з миттєвим перемиканням класу `dark` на тегу `<html>` і збереженням у `localStorage.theme`.

### 4.2. Ліва навігаційна панель (Sidebar)
- Фільтр-список за типами виробів (Гайки, Шайби, Різьби, Моменти).
- Список стандартів із мітками шифру (напр., `ГОСТ 5915-70`, `ISO 4032`).
- Кнопка згортання бічної панелі (`#btnToggleSidebar`) для максимізації області таблиці на екранах ноутбуків.

### 4.3. Паспорт стандарту (Passport Card)
- Розміщується над таблицею у вигляді напівпрозорої картки `fluent-card`:
  - Шифр та офіційна назва стандарту.
  - Бейджі: клас точності, доступні виконання, одиниці виміру (`мм`, `Н·м`).
  - Офіційні примітки щодо сфери застосування та нерекомендованих розмірів у дужках.
  - Посилання на джерело та статус верифікації.

### 4.4. Таблиця розмірів (Master Table)
- **Панель пошуку:** поле швидкої фільтрації за діаметром (введення `24` або `M24` миттєво відсіює потрібний рядок).
- **Перемикачі параметрів:** вибір виконання (Вик. 1 / Вик. 2) та класу точності (Клас A / Клас C), якщо стандарт це передбачає.
- **Стовпчики:** чіткі інженерні позначення параметрів ($d$, $P$, $m$, $S$, $e$, $d_1$, $d_2$, $s$ тощо).
- **Інтерактивність:**
  - `hover`: підсвічування рядка та миттєве оновлення розмірів на правому кресленні.
  - `click`: фіксація активного рядка для збереження фокуса.
  - Sticky Header: заголовок таблиці зафіксований при прокручуванні списку діаметрів.

### 4.5. Блок інтерактивного креслення (Sticky Detail Panel)
- Закріплений праворуч блок із постійно видимим векторним кресленням (SVG).
- **Зображення деталі:**
  - Гайки: фронтальний розріз із різьбою + вигляд згори (шестигранник).
  - Шайби: піврозріз + вигляд згори (отвір та зовнішній діаметр).
  - Різьби: метричний профіль різьби $60^\circ$ із кроком $P$ та діаметром $d$.
  - Моменти: інфографічна шкала діапазону затягування.
- **Розмірні лінії за ДСТУ/ГОСТ:** тонкі виносні лінії, стрілки розмірів, числові значення розмірів для вибраного рядка.
- **Керування:**
  - Бейдж зі стандартним позначенням (напр., `Гайка М24-6H ГОСТ 5915-70`).
  - Кнопка **«Скопіювати позначення»** (копіювання в буфер обміну + спливаючий тост).
  - Кнопка **«Експорт SVG»** (завантаження креслення файлом).
- **Адаптивність стилю креслення:**
  - Світла тема: світлий фон, чіткі темні лінії деталі, бірюзові розмірні лінії.
  - Темна тема: темно-синій креслярський фон (Blueprint), неоново-блакитні контури, білі контрастні розміри з підкладкою.

## 5. Граничні випадки (Edge Cases)

1. **Нерекомендовані діаметри:** якщо розмір вказано в дужках за стандартом (наприклад, M14, M18, M22, M27 у ГОСТ 5915-70), він виділяється стилем тексту *(нерек.)*, а в паспорті відображається пояснення.
2. **Відсутність окремих розмірів:** якщо для певного виконання розмір не нормується (наприклад, у ГОСТ 11371 для M33 клас C = null), виводиться тире `—`, а креслення адаптує розмірні лінії.
3. **Порожній результат фільтра:** виведення повідомлення `Розмірів не знайдено` із кнопкою швидкого скидання фільтра.
4. **Робота без інтернет-з'єднання:** 100% автономність, відсутність зовнішніх шрифтів Google Fonts чи CDN скриптів.

## 6. Стратегія тестування та перевірка

1. **Регресійне тестування розрахункового ядра:**
   - Команда: `node scripts/check.cjs`
   - Критерій: 100% проходження всіх існуючих тестів, 0 розбіжностей у розрахунках фланцевих з'єднань.
2. **Новий автономний тестовий набір `tests/standards-base.test.cjs`:**
   - Перевірка повноти адаптера: всі 10 стандартів (5 гайок, 3 шайби, 1 різьба, 1 таблиця моментів) коректно реєструються та мають валідні схеми колонок.
   - Перевірка генерації SVG: для кожного діаметра кожного стандарту генерується коректний SVG-код без `NaN`, `undefined` або від'ємних геометричних радіусів.
   - Перевірка фільтрації: тест функції пошуку за діаметрами.
3. **Візуальна верифікація:**
   - Запуск локального сервера та перевірка коректності відображення у браузері на світлій та темній темах.

## 7. Подальша інтеграція з SuperBase

Оскільки `standards-base` використовує:
- Той самий `tailwind-local.css`
- Ті самі кольорові токени та назви класів (`glass-panel`, `fluent-card`, `dark:bg-dark-panel`, `brand-glow`)
- Той самий механізм теми (`localStorage.theme`, `html.dark`)
- Автономну модульну структуру

У майбутньому цей розділ може бути без змін підключений до `SuperBase` як окремий пункт меню (наприклад, поруч зі «Шпаргалкою» чи в головній навігації).
