# Зусилля, герметичність і нижня межа

Джерело формул — «Вузол №1» початкового Excel, I/J27–49 та N52:O58. `calculations.js::forces` обчислює один режим; `nodeForces` збирає входи з анкети, актуальних матеріалів та нормативного каталогу. Перевірка: `node tests/forces.cjs`.

## Входи й одиниці

- Момент для перевірки конкретного затягу: `fastener.torqueNm`, Н·м. Це необов’язкове поле для нижньої межі. У C6 Excel момент задано в Н·мм, тому перед визначенням зусилля застосовується множник 1000.
- Діаметр — мм, площі — мм², тиски — МПа; зусилля — Н.
- ζ₁ = 0,26 з мащенням та 0,37 без мащення. m підбирається окремо за середовищем кожного режиму.
- q₀, qmin, qmax надходять із вибраного довідника прокладки. Температурні правила залишаються за `THERMAL.md`.

## Формули

| Величина | Формула | Комірки |
| --- | --- | --- |
| Початкове зусилля одного кріплення | F₀₁w = M·1000/(ζ₁·d) | I/J27 |
| Сумарне початкове зусилля | F₀w = F₀₁w·z | I/J28 |
| Зусилля герметичності | Fпр = Aпр·m·p | I/J29 |
| Гідростатичне зусилля | Fp = A·p | I/J30 |
| Початкове обтиснення | F₀b = Aпр·q₀ | I/J31 |
| Зусилля в комплекті кріплень | Fw = F₀w + χ·Fp + Ft | I/J33 |
| Зусилля на прокладку | Fqпр = F₀w − (1−χ)·Fp + Ft | I/J34 |
| Необхідний початковий затяг за герметичністю | Fгерм = Fпр + (1−χ)·Fp + Ft | I/J43 |
| Питомий тиск | q = Fqпр/Aпр | I/J44 |
| Необхідний затяг за qmin | Fqmin = qmin·Aпр + (1−χ)·Fp − Ft | N/O55 |

**Знак Ft збережено за Excel:** у I43 використовується +Ft, а в N55 — −Ft. Умова I43 не замінена алгебраїчним перетворенням I34. Для ГВ Ft = 0 за погодженням користувача, тому відсутній доданок у J43 не змінює результату.

Чотири незалежні перевірки для кожного режиму: F₀w ≥ F₀b; F₀w ≥ Fгерм; q ≥ qmin; q ≤ qmax. Рівність дозволена. Від’ємне зусилля/тиск при розвантаженні зберігається й дає невиконану нижню умову. Відсутній вхід дає невизначену перевірку, а не нуль чи успішний статус.

Нижня межа — максимум п’яти зусиль: обтиснення, герметичність НУЕ/ГВ, qmin НУЕ/ГВ. Mmin = Fmin·ζ₁·d/(z·1000). Показується визначальна умова, а при рівності — всі однакові максимуми. Заголовок показує округлення вгору до цілого Н·м, як `ROUNDUP(N58,0)` у P88; в таблиці окремо доступне значення до підсумкового округлення. Подальша математика використовує повну точність.

Неповні обов’язкові критерії НУЕ/ГВ блокують загальний мінімум. Незаповнений заданий момент не блокує нижню межу, але залишає невизначеними перевірки конкретного затягу. Перевірки міцності кріплення й різьби та попередній максимум реалізовані окремо (`STRENGTH.md`). Міцність активних фланців також підключена (`FLANGES.md`). Повний контроль потребує визначеної застосовності обох деталей і проходження перевірок обох округлених меж.

## Звіряння

Скрипт `scripts/extract-control-node.py` незалежно перевіряє 25 зусиль, тисків і величин нижньої межі за збереженим кешем, не змінюючи книгу. JS-перевірка відтворює 18 значень I/J27–44 та нижню межу 125,40225188034657 Н·м → 126 Н·м за вихідними властивостями й старим температурним внеском Excel.

Це перевірка перенесення арифметики. Живий розрахунок використовує погоджену табличну α і актуальні характеристики/розміри каталогів, тому не зобов’язаний повторювати старий кеш. Браузерна перевірка виконана на окремому тимчасовому вузлі зі сталлю 35Х: зміна 150 → 50 Н·м змінює статус перевірок; поле відновлюється після перезавантаження. Тестові дані видалені після перевірки.
