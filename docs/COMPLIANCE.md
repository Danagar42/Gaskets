# Податливість і коефіцієнт навантаження

Реалізовано в `calculations.js`: `compliance` обчислює величини з явних входів у мм, Н та МПа; `nodeCompliance` отримує ці входи з вузла й актуальних довідників окремо для НУЕ/ГВ. Інтерфейс — `app.js::complianceBlock`. Навантаження, температурні зусилля, перевірки міцності та кінцеві моменти тут ще не обчислюються.

## Формули з контрольної книги

Джерело: `Насос 600В-1,6_100.xlsx`, аркуш `Вузол №1`, I4:J18. Тексти формул і збережені значення включені в `tests/fixtures/control-node-1.json`. Це збережені результати книги; повний перерахунок Excel не виконувався.

| Величина | Формула | Комірки НУЕ/ГВ |
| --- | --- | --- |
| Податливість прокладки | hпр / (Eпр · Aпр) | I4 / J4 |
| Шайби одного боку | hш / (z · Eш · Aш) | I8 / J8, I9 / J9 |
| Корпусна деталь Б | hБ / (EБ · AБ) | I10 / J10 |
| Деталь А | hА / (EА · AА) | I11 / J11 |
| Поправка різьбової частини 1 | 0,49√(1,44 + 9,28·P/d₃) / (d₂·Ew) | I13 / J13 |
| Поправка різьбової частини 2 | Та сама формула | I14 / J14 |
| Нерізьбова частина одного кріплення | L* / (Ew · Aгладк) | I15 / J15 |
| Різьбова частина одного кріплення | L** / (Ew · Aрізьби) | I16 / J16 |
| Комплект короткого кріплення, L* < 6d₀ | Сума I13:I16, поділена на z; аналогічно J | I17 / J17 |
| Комплект довгого кріплення, L* ≥ 6d₀ | Тільки податливість нерізьбової частини, поділена на z | I17 / J17 |
| Коефіцієнт χ | λпр / (λпр + λдеталей + λшайб + λдодаткових + λw) | I18 / J18 |

На всіх чотирьох аркушах джерела I13/I14 мають однакову формулу, включно з наскрізним болтом. Обидві поправки збережені. Гілка довгого кріплення також збережена дослівно за змістом; при переході через L*=6d₀ можливий стрибок результату. Методика в цьому етапі не змінювалася.

Неактивні додаткові складові контрольного вузла I5/I6/I7/I9/I12 та J-аналоги дорівнюють нулю. Для доданих користувачем проставок постійного перерізу застосовується сума h/(E·A), як для прямого призматичного елемента. Ступінчастий бурт/«рубашка» та додаткові прокладки цим загальним елементом не моделюються.

## Площі та довідники

- Для кільцевого вузла порожні поля площ деталей А/Б означають автоматичний розрахунок π(b₀·Dсер − z·dотв²/4), як C89/C101 контрольного вузла. Це фактичний переріз кільцевого поля; він відрізняється від ефективної площі прокладки Aпр.
- Кожну площу А/Б можна перевизначити явним числом. Нуль або некоректне введене число не означає «авто».
- При ручному заданні площ нестандартної прокладки площі деталей А/Б вводяться окремо: ефективної площі прокладки недостатньо для їх визначення.
- Для шайб беруться розміри активного стандарту. Їхній переріз для цієї формули — `3.1415 · Dсер · b`, зі збереженням коефіцієнта з I8/J8. Кожен бік враховується один раз; кількість z стоїть у знаменнику.
- Для металів E читається з бази за заданою або найближчою більшою доступною температурою та перетворюється з ГПа в МПа множенням на 1000. Під таблицею можна переглянути фактичні температури й модулі кожного компонента.
- Eпр береться з вибраного набору характеристик прокладки. Її α для цього блока не потрібна.

Нові стандартні розміри шайби можуть відрізнятися від введених вручну чисел старого Excel. Тому точне звіряння виконується на старих явних входах, а інтеграційна перевірка — на актуальних розмірах каталогу. Різниця кінцевого χ при різних входах не маскується.

Оновлення 14.11.2026: користувач додав E та α для «Чавун СЧ25». Для «Сталь 25Л» E/α ще відсутні у data.js; з дозволу користувача для наскрізної звірки використано числа Excel лише в контрольному наборі. Загальна база матеріалів цією перевіркою не змінюється. Деталі — `VERIFICATION_2026-11-14.md`.

## Відсутні дані та показ результатів

Неактивна шайба чи відсутні проставки дають нульовий внесок. Активний елемент із невідомою висотою, площею або E дає недоступну податливість і не дозволяє отримати залежний χ. НУЕ й ГВ перевіряються незалежно; один режим може бути обчислений, а другий — ні.

Податливості відображаються в науковому форматі, щоб 10⁻⁷ чи 10⁻¹⁰ не виглядали нулями. χ — безрозмірний. Проміжні значення не округлюються для наступних обчислень.

## Перевірки

`python scripts/extract-control-node.py` незалежно звіряє 14 величин геометрії й 20 величин податливості з кешами джерела та перевіряє незмінність XLSX під час читання.

`node tests/compliance.cjs` звіряє 20 величин I/J4–18 та перевіряє поріг L*=6d₀, шайби з обох боків, проставку, відсутні E/площі, перетворення одиниць, вибір температури й ручні площі. Для старого контрольного набору χ: НУЕ 0,7473982849590467; ГВ 0,7499638549624352.
