# Контрольний вузол №1: карта даних і перший блок формул

Статус: 13.11.2026 користувач підтвердив поріг b₀ > 15 мм і правило суми різьбових/нерізьбових висот. Геометрія підключена через `calculations.js`; наступні блоки навантаження та міцності ще не обчислюються.

Джерело: `Насос 600В-1,6_100.xlsx`, аркуш `Вузол №1`. Повний вибірковий знімок входів, формул і збережених значень: `tests/fixtures/control-node-1.json`. У JSON записаний SHA-256 джерела. Вихідна книга не змінювалася.

Повторне отримання: `python scripts/extract-control-node.py`. Потрібна лише стандартна бібліотека Python. Скрипт звіряє 14 геометричних величин незалежним числовим розрахунком. Він не перераховує всю книгу та не підтверджує кінцеві межі моменту.

## 3. Формули геометрії з Excel

Тут наведена фактична логіка книги. Її застосовність до нового довідника прокладок ще потребує рішення G1 нижче.

| Комірка | Величина і формула | Збережене значення |
| --- | --- | --- |
| C16 | Реальна ширина b₀ = (D₁ − D₂) / 2 | 75 мм |
| C17 | Ширина по отвору = b₀ − dотв | 51 мм |
| C18 | b = 3,8√b₀, якщо b₀ > 15; інакше b₀ | 32,9089653438 мм |
| C19 | bотв = 3,8√(b₀ − dотв), якщо **b₀ > 15**; інакше b₀ − dотв | 27,1374280285 мм |
| F22 | Dсер = (D₁ + D₂) / 2 | 1225 мм |
| C22 | Aпр = π(b·Dсер − z·dотв²/4) | 112172,0816599125 мм² |
| C23 | A = π((D₁ + D₂)/4)² | 1178588,1189482957 мм² |
| C33 | d₃ = d₀ − 2·(17/24)·(0,5·t·tan60°) | 20,3193920339 мм |
| C35 | d₂ = d₀ − 2·(3/8)·(0,5·t·tan60°) | 22,0514428415 мм |
| C38 | L* = hкришки + hпрокладки + hшайби | 61 мм |
| C39 | L** = Lкорпус + Lгайка | 57,5 мм |
| C47 | Aгладк = 0,785(d₀² − dₕ²) | 452,16 мм² |
| C48 | Aрізьби = 0,785(d₃² − dₕ²) | 324,1089887130 мм² |
| C89 | Aдеталі = π(b₀·Dсер − z·dотв²/4) | 274157,3661008205 мм² |

Всі 14 значень незалежно звірені зі збереженими значеннями книги. У перевірці збережені саме `0,785` і умова C16 > 15 у C19. Точні тексти формул і числа без округлення є в JSON.

Площа A у C23 визначається за середнім діаметром прокладки, а не за внутрішнім. Для режиму ручних площ зміст обох введених величин має відповідати погодженій методиці.

## 4. Рішення перед перенесенням

### G1. Ефективна ширина прокладки

- Excel C18 використовує зменшену ширину 32,9089653438 мм.
- Новий каталог Б.1 містить `effectiveWidth.rule = equalsSealingBandWidth` — ширина поля ущільнення.
- Якщо під шириною поля в цьому прикладі прийняти b₀=75 мм і лишити формулу C22, Aпр становитиме 274157,3661008205 мм² замість 112172,0816599125 мм².

Рішення користувача: при b₀ > 15 мм використовується `3,8√b₀`, при b₀ ≤ 15 мм — b₀. У робочій геометрії збережене зменшення ширини з Excel; правило каталогу Б.1 показується як дані джерела й не підміняє погоджену розрахункову формулу. Друге число вище залишається порівнянням.

### G2. Довжини зачеплення

Рішення користувача: різьбова довжина — сума висот елементів із різьбою; нерізьбова — сума висот елементів без різьби. Для шпильки в корпусі: деталь Б і гайка — різьбові; деталь А, прокладка, шайби та проставки — нерізьбові. Для наскрізного болта обидві основні деталі нерізьбові, гайка різьбова. Для шестигранної гайки використовується таблична висота. Для ковпачкової гайки загальна l₁ не підставляється: потрібне окреме значення висоти різьбової частини. Сума довжин пакета не оголошується готовою замовною довжиною кріплення.

### Далі, перед температурним блоком

У старій книзі α прокладки задана формулою залежності від температури. Новий каталог має точні значення Б.2 від 50 до 400 °C; для НУЕ=45 °C і ГВ=20 °C точних значень немає. Це окреме питання наступного блока, яке не заважає погодженню геометрії.

## 5. Майбутня перевірка повного розрахунку

У джерелі збережено P88=126 Н·м і P89=374 Н·м. Це історичні результати книги з її вхідними характеристиками й формулами. Вони не є підтвердженими результатами нового застосунку або варіанта з новими довідниками.

Після геометрії перевіряються податливості, температурні складові, зусилля, герметичність та міцність. Порівняння тільки двох кінцевих чисел недостатнє: звіряються проміжні величини й визначальне обмеження.
