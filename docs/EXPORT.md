# Файли проєкту та Excel

Реалізовано 14.11.2026. Працює локально, зокрема при відкритті `index.html` без сервера.

## Резервна копія JSON

Кнопка **«Файл проєкту»** у заголовку зберігає весь простір: обладнання, вузли, конструктор, параметри та посилання на матеріали/КП. Характеристики металів після відновлення читаються з актуального `data.js`.

Для імпорту спочатку показуються обладнання та кількість вузлів. За замовчуванням додаються копії з новими ідентифікаторами. Можна вибрати відновлення всього проєкту; попередній стан зберігається під ключем `flange-workspace-v1-before-import` і доступний для завантаження в тому самому діалозі. Підтримуються попередні JSON зі структурою локального сховища версії 1. Ліміт файла — 10 МБ.

Ліміт рахується в байтах UTF-8. Якщо читабельний JSON із відступами завеликий, експортується компактний без втрати даних. Якщо й він перевищує 10 МБ, файл не створюється та показується причина; копія, що не пройде власний імпорт, не завантажується.

Файл перевіряється до запису. Новий стан спочатку записується в localStorage й лише після успіху стає активним. Невідомий формат, пошкоджений JSON, повторні/некоректні ID або помилка запису не замінюють робочий простір.

## Початковий Excel

**«Експорт Excel»** над розрахунком формує один вузол; **«Excel обладнання»** у папці — всі її вузли в одній книзі, до 100 аркушів. Порожні/неповні вузли блокують відповідний експорт із причинами. Несумісні межі або погоджений пропуск чавунної різьби допускають діагностичний файл із попередженням.

Момент перевірки для C6 вибирається в діалозі: заданий в анкеті або запропонований округлений максимум. Анкета від цього не змінюється. У файл він переходить у Н·мм, межі P88/P89 залишаються в Н·м.

`excel-template.bundle.js` містить незмінений оригінальний XLSX (SHA-256 `935da68691f6be6a3263340be97af5b499d41383b8f1ec3b636d6c47e6336bab`). `excel-export.js` копіює потрібні аркуші та їхні залежності, зберігає стилі, злиття, малюнки, примітки й параметри друку. Числові результати залишаються формулами; старі кеші видаляються, вмикається повний перерахунок при відкритті. Для читання шаблону використовується браузерний `DecompressionStream('deflate-raw')`, мережа не потрібна. Якщо Excel уже працює в ручному режимі обчислення, виконайте повний перерахунок Ctrl+Alt+Shift+F9.

Погоджені зміни відносно старого файла:

- α прокладки — за найближчою вищою табличною температурою; розширення кріплення та температурне зусилля ГВ — нуль.
- Довжини включають обидві шайби та всі проставки; кількість шайб на боці дорівнює числу кріплень. Обидва режими використовують одну висоту різьбової частини гайки.
- Проставки впливають на податливість і довжини, їхнє розширення виключене. Для кількох елементів додається редагований аркуш **«Проставки»** з окремими h, A, E та формулами λ.
- Ручні площі експортуються без вигаданих діаметрів кільця. Порожня площа основної деталі в кільцевому вузлі залишається формулою кільцевого поля.
- Застосовність фланців та чавунні гілки беруться з анкети. Погоджені особливості N67 і відсутніх верхніх N68/N69 збережені.
- Неактивна шайба дає числову нульову податливість у НУЕ й ГВ. Старі текстові заглушки не переривають гідровипробування.

**Схеми з оригіналу не перебудовуються під нові розміри.** Це зазначено в діалозі та примітці під розрахунком. Властивості металів — знімок актуальної бази на час експорту; книга не підключається до `data.js`. Після зміни температури в Excel властивості металів треба перевірити, як і в початковому файлі. Сам оригінал застосунок не перезаписує.

## Перевірка

У Microsoft Excel книга відкрилася без відновлення, пройшла повний перерахунок і збереження. `scripts/verify-excel-export.py` зіставив **1088 числових значень без розбіжностей**, включно з проміжними величинами та межами. На кожному основному аркуші залишилися три вихідні графічні об’єкти й формули P88/P89. Знімок результату — `tests/fixtures/excel-export-verification.json`.

| Варіант | Мінімум, Н·м | Максимум, Н·м |
| --- | ---: | ---: |
| Вузол №1 | 126 | 374 |
| Вузол №2 | 89 | 379 |
| Вузол №3 | 63 | 406 |
| Вузол №4 | 112 | 248 |
| Дві шайби та дві проставки | 128 | 376 |
| Ручні площі | 126 | 374 |
| Болт без шайб | 122 | 370 |
| Нульовий тиск ГВ | 110 | 521 |

Для 25Л лише в контрольному наборі використані погоджені раніше E/α з Excel; виробничий `data.js` не доповнюється прихованими значеннями. Внутрішня різьба СЧ25 без Rp у вузлі №4 явно пропущена, її міцність цією звіркою не підтверджена.

У тестовій копії вручну змінено C40 вузла №1 з 32 на 33 й виконано повний перерахунок: межі стали 121–377 Н·м. Після повернення 32 відновлено 126–374 Н·м. Перевірено також імпорт із попереднім переглядом, відмову для стороннього JSON, завантаження JSON та XLSX через інтерфейс. Тимчасове тестове обладнання видалене.

Повторення автоматичних перевірок:

```powershell
node tests/project.cjs
node tests/excel-export.cjs
```

Повторення нативної звірки: `node tests/excel-export.cjs --write`, відкрити `inspection_scratch/verification/export-test.xlsx` у Microsoft Excel, повністю перерахувати та зберегти, потім `python scripts/verify-excel-export.py inspection_scratch/verification/export-test.xlsx`. Без `--write` тест не створює робочих файлів. QA-файли не є персональним проєктом.

Якщо оригінальний шаблон змінено, явно перебудувати bundle командою `python scripts/build-excel-template.py` і повторити звірку.
