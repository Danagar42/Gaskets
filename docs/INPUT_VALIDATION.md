# Перевірка введених величин

Правила зібрані в `core.js::validateInputs`. Один і той самий результат використовується в анкеті, станах заповнення, підтвердженні діапазону та перевірці перед Excel-експортом.

- Приймаються звичайні десяткові числа з комою або крапкою. Текст, одиниці вимірювання всередині значення, неоднозначні роздільники та нескінченні числа відхиляються. Одиниці видно поруч із полем.
- Тиск і заданий момент можуть дорівнювати нулю; від’ємні значення недопустимі. Температура — не нижче −273,15 °C. Для НУЕ додатково потрібна доступна таблична α прокладки. Температурне зусилля ГВ лишається нульовим за погодженим правилом.
- Товщини, висоти, діаметри й ручні площі додатні. Кількість кріплень — додатне ціле число в межах точно представлених чисел.
- Номінальний діаметр і крок різьби мають бути в обраному каталозі. Якщо автоматичного великого кроку немає, потрібен явний вибір. Поздовжній отвір кріплення допускає нуль і має бути меншим за d₃.
- Для кільцевої прокладки Dзовн > Dвн; отвір менший за ширину кільцевого поля; після врахування кількості отворів ефективна площа додатна. Переповнення обчислюваних площ позначається помилкою.
- Для фланця перевіряються D < Dw < Df, D < Dm < Df та додатна перемичка Df−D−2d₀. Нульова висота конічної частини допустима.
- Різьбова висота ковпачкової гайки обов’язкова й не більша за загальну висоту гайки з каталогу.
- Проставки мають додатну товщину та площу перерізу.

Порожня площа основної деталі для кільцевої прокладки означає автоматичний розрахунок. При ручних площах прокладки площі деталей А/Б обов’язкові. Порожній отвір фланця означає автоматичний табличний припуск. Порожній момент перевірки не заважає обчисленню незалежних меж. Поля вимкнених елементів конструкції не перевіряються.

Незаповнені обов’язкові поля одразу підсвічуються бурштиновим і мають підказку під полем або всередині картки матеріалу. Це стосується розмірів, назв деталей, обов’язкових виборів у списках і матеріалів. Автоматичні значення не потребують ручного заповнення. Некоректні введені значення позначаються червоним. Підсвічування й підказки оновлюються після зміни значення або схеми вузла.

Над анкетою є лічильник і кнопка переходу до першої помилки. Вона відкриває потрібний розділ і фокусує поле. Помилки зв’язані з полями через `aria-describedby`, стан — через `aria-invalid`.

За помилок введення діапазон не показується як підтверджений, а Excel-експорт блокується з поясненнями. Частково заповнені анкети можна зберігати в браузері й JSON та доповнювати пізніше. Геометрична перевірка не додає непогоджених верхніх робочих тисків, максимальних розмірів чи вимоги ГВ ≥ НУЕ.

Перевірки: `tests/validation.cjs` — 37 помилкових значень, залежності розмірів, автоматичні й вимкнені поля, блокування підтвердження/експорту. У браузері перевірено від’ємний тиск, десяткову кому, температуру 401 °C, взаємозалежні діаметри й отвір прокладки, зникнення помилок після виправлення та перехід до першої помилки. Тимчасову анкету видалено. Загальний запуск: `node scripts/check.cjs`.
