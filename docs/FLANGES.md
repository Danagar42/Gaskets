# Фланці: геометрія, міцність та межі

Реалізація — `calculations.js::flange/nodeFlanges`, інтерфейс — `app.js::flangeBlock`. Джерело — блоки Q–X усіх чотирьох вузлів початкового Excel. Перевірки — `node tests/flanges.cjs`. Джерельний XLSX не змінюється.

## Входи конструктора

Для кожної основної деталі зберігається окремий запис `node.flanges.sideA/sideB`. Матеріал береться з відповідної `connection.sideA/sideB.material`, без копіювання характеристик.

`mode`: `pending` — застосовність ще не визначена; `flange` — активний розрахунок; `none` — користувач явно визначив, що ця перевірка не застосовується. Нові й старі анкети починають із `pending`, тому відсутні налаштування не видаються за успішну перевірку. Уже введена геометрія зберігається при зміні застосовності.

| Поле | Позначення, мм | Excel для А / Б |
| --- | --- | --- |
| innerDiameter | Внутрішній D | W4 / R4 |
| boltCircle | Коло кріплень Dw | W5 / R5 |
| outerDiameter | Зовнішній Df | W6 / R6 |
| gasketDiameter | Розрахунковий Dm | W7 / R7 |
| holeDiameter | Отвір d₀ | W8 / R8 |
| height | Висота фланця й бурта hf | W9 / R9 |
| coneHeight | Висота конічної тарілки h₂, може бути 0 | W10 / R10 |
| wallCylinder | Товщина s₁ | W11 / R11 |
| wallCone | Товщина s₂ | W12 / R12 |

Для кільцевої прокладки Dm обчислюється за середнім діаметром; для ручних площ його потрібно ввести. Порожній d₀ означає джерельну формулу: d+3 при d≥27, d+2 при 10<d<27, інакше d+1. Фактичний отвір можна вказати явно: у контрольному вузлі W8=24, а не автоматичні 26 мм. Цей отвір незалежний від отворів прокладки та поздовжнього отвору кріплення.

hf не зв’язаний автоматично з висотою деталі в податливості пакета. Це різні входи, які в окремій конструкції можуть збігатися.

## Геометрія та формули

Збережено e₁=(Dw−D−s₁)/2, e₂=|Dw−Dm|/2, e₃=(Dw−(Dm+D)/2)/2. Координата y, WA та обидві гілки WB відтворюють рядки 22–24, включно з коефіцієнтами 0,33, 0,125 та 0,25. s₀=p·D/(2[σ]); моменти опору мають одиниці мм³, згинальний момент Fw·e₂/1000 — Н·м.

Гілка WB з діленням на h₂ виконується лише при y>hf. При h₂=0 використовується плоска гілка. C–C перевіряється при hf≤s₂; при строгій нерівності hf>s₂ вона не потрібна за джерельною гілкою. WC=π(Df−2d₀)hf²/4 для активного C–C.

Валідація вимагає D<Dw<Df, D<Dm<Df, додатну перемичку Df−D−2d₀ й додатні активні моменти опору. Невизначена або некоректна активна геометрія не замінюється нулем і блокує максимум. Якщо e₂=0, згинальне напруження нульове й окремого верхнього обмеження за цим перерізом немає; це явний необмежувальний стан, а не відсутній вхід.

## Допустимі напруження

Rm (`RTm`) та Rp (`RTp`) беруться з актуальної бази за точною/найближчою вищою доступною температурою режиму. Використані точки показуються біля результатів.

- Базове [σ] = min(Rm/2,6; Rp/1,5). У вихідному Excel є явний IFERROR-резерв: якщо доступна лише одна характеристика, використовується її вираз.
- Для чавуну НУЕ [σ] = Rm/2,2. Сірий чавун розпізнається за назвою матеріалу «Чавун …»/«СЧ…», а не за назвою обладнання чи деталі. Для ГВ залишається базове правило Rm/2,6 та Rp/1,5.
- Напруження σ₂ в А–А та B–B: 4Fp/[π((D+2s)²−D²)], де s=s₂ або s₁. Допустимі значення — 1,3[σ] для НУЕ, 1,7[σ] для ГВ; для чавуну НУЕ — Rm/2,2.
- Приведені напруження σrv = Fw·e₂/W. Для сталі НУЕ допустиме min((2,5−Rp/Rm)Rp; 2Rp), з явним джерельним резервом 2Rp за відсутності Rm. Для чавуну А–А/B–B НУЕ — Rm/2,2.
- Збережено асиметрію C–C: W46 (деталь А) використовує вираз Rp/Rm навіть для чавуну; R46 чавунної деталі Б у вузлі №4 має гілку Rm/2,2. Вузол №1 не потребує активного C–C через hf>s₂, тому це не змінює його контрольні значення. Різницю не уніфіковано приховано; для її зміни потрібне окреме рішення щодо методики.
- Приведені напруження ГВ та відповідні обмеження відсутні у всіх чотирьох аркушах; вони позначаються незастосовними. Перевірки σ₂ ГВ залишаються активними.

## Інтеграція з верхньою межею

Для кожного активного приведеного напруження НУЕ: F₀max=[σrv]W/e₂−χFp−Ft. Відповідність: деталь Б → N/O76–78, деталь А → N/O80–82. Активні фланцеві обмеження додаються до того самого MIN кріплення та різьби. Невідомий активний переріз блокує максимум; відомий слабкий фланець може визначити максимум або зробити межі несумісними.

За невизначеної застосовності хоча б однієї деталі результат позначається попереднім. Відомі активні фланці вже враховуються; вони не відкидаються через незаповнений інший бік. Після явного визначення обох деталей і проходження всіх наявних перевірок **обох округлених меж** показується «Межі перевірено». Це результат перенесеної методики й заданої застосовності, а не незалежне нормативне підтвердження будь-якої конструкції.

N67 та відсутні в початковому MIN окремі обмеження σ₄/кручення/qmax збережені, як описано у `STRENGTH.md`. Повторна перевірка меж виявляє невиконані умови, не змінюючи заданий користувачем момент.

## Звіряння та обмеження

Екстрактор охоплює 6 активних фланців із усіх 4 вузлів у двох режимах: 12 наборів, 200 незалежно звірених проміжних величин. JS-тест звіряє також 14 числових верхніх обмежень. Додатково перевірені h₂=0, hf=s₂, e₂=0, відсутні характеристики, резервні вирази, чавунні гілки, ручний Dm, некоректна геометрія, слабкий фланець та інтеграція з контролем меж.
